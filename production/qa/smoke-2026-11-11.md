# Smoke check, 2026-11-11

`npm run smoke` against the local development server (`npm run dev -- --port 5273`), at commit f5bc724 plus `tools/smoke.mjs` itself.

What it does: loads the page, reads the list of rooms, makes a listed room with four players over real WebSockets, sends a chat line, asks for voice (refused in a listed room), pings, starts a game, plays it to its end and leaves.

```text
ok   the page loads: status 200
ok   a plain request to the list of rooms is refused: status 404
ok   the list of rooms answers: 1 room(s) listed
ok   four players are in the room: smoke0 smoke1 smoke2 smoke3
ok   the list shows the room with its host and head count: {"code":"K8JH4","game":"russian-roulette","host":"smoke0","players":4,"maxPlayers":6,"playing":false}
ok   a chat line reaches everyone, cleaned
ok   voice is refused in a room on the list: voice-not-here
ok   a ping is answered
ok   someone who is not the host cannot start: not-host
ok   the game starts with a seat each: seats 0 1 2 3
ok   the list says a game is being played
ok   no token is ever sent to anyone
ok   other seats' credits and deposits are not in a player's view
ok   the game plays to its end: 70 moves
ok   everyone is shown the same ending
ok   as many seats are hit as there were live rounds: 1 round(s), hit 2
ok   the room leaves the list when everyone has left
17 of 17 checks passed against http://localhost:5273
```
