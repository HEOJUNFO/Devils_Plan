# 비밀 코드 (Secret Code)

유배지 매치 03. 2026-11-27에 만들었다 (`src/shared/games/secret-code/`,
`src/client/games/secret-code/`, `tests/unit/secret-code/`, `tests/integration/secret-code/`).

## Rules as documented

나무위키 「유배지」 문서에는 이름과 결과만 있다 (2026-11-27: 1등·2등·3등·4위(탈락)). 규칙은
7화 영어 자막에서 읽었다 (00:18:37~00:28:00, 조사 에이전트가 한 번 읽음. 자막 문장은 옮겨
적지 않고 뜻만 적는다).

1. 제시된 그림을 보고, 나열된 조건을 모두 만족하는 코드를 찾는다 (00:18:58).
2. 코드는 글자 네 개이고 알파벳 순서로 답한다 (00:19:06).
3. 버저를 누르면 10초 안에 답한다 (00:19:16).
4. 틀리면 그 문제에서 잠겨 같은 문제에 다시 답할 수 없다 (00:19:20).
5. 맞히면 즉시 생존이 확정되고 남은 게임에서 빠진다 (00:19:26).
6. 3라운드를 하고, 끝까지 맞히지 못한 사람이 탈락한다 (00:19:33).
7. 그림은 카드 26장이다: 카드마다 A~Z 글자 하나, 수, 모양(suit)이 있다 (출연자의 말,
   00:20:27). 색은 조건 문장에만 나온다.

라운드별 조건의 종류 (화면 자막):

- 1라운드 (정답 A·O·Q·V): 네 수의 합이 55 / 색이 2가지 / 모양이 3가지 / 두 번째와 네 번째
  카드의 수의 차가 7 / 두 번째로 작은 수의 카드의 모양이 A~Z 가운데 두 번째로 많은 모양.
- 2라운드 (정답 A·N·P·W): 합이 54 / 색 4가지 / 모양 2가지 / 첫 번째와 네 번째 카드의 수의
  곱이 50 이하 / 가장 큰 수와 가장 작은 수의 합이 20 이상 / 세 번째로 작은 수의 카드의 색이
  A~Z 가운데 가장 적은 색.
- 3라운드 (정답 C·L·M·S): 합이 50 이하 / 색 2가지 / 모양 4가지 / (출연자의 말로) 가장 큰
  수가 가장 많은 색의 카드에 있음. 화면 자막은 여기서 끊겨 조건이 더 있었는지는 모른다.

**읽어 낸 것 (자막에 직접 나오지 않음):** 수는 알파벳 순서다 (A=1 … Z=26). 세 라운드의
정답이 수에 관한 조건을 그렇게 볼 때만 만족한다 (1+15+17+22=55, 22−15=7; 1+14+16+23=54,
1×23≤50, 1+23≥20; 3+12+13+19=47≤50). `tests/unit/secret-code/documented.ts`가 이것을 잡는다.

**방송에 없는 것:** 어느 카드가 무슨 색·모양인지 (화면에만 나옴. 자막에는 모양 이름 circle,
star와 색 이름 green, pink뿐), 색과 모양이 몇 가지인지 (조건으로 보아 각각 넷 이상), 풀이
제한 시간, 한국어 용어 (7화 한국어 자막을 읽지 못했다).

## 방을 위해 채운 것

- **인원 2~6명.** 혼자 시작할 수 없다 (`.claude/rules/bots.md`).
- **카드:** 색 4가지와 모양 4가지를 판마다 무작위로 나눈다. 장수는 9·7·6·4로 서로 달라
  "가장 많은 색"이 하나로 정해진다 (`config.json`). 색 두 가지(파랑, 노랑)와 모양 두 가지
  (세모, 네모)는 방송에서 이름을 알 수 없어 정했다. 카드는 한 판 내내 같다.
- **조건은 판마다 만든다** (`makeRound`): 코드 하나를 뽑고, 그 코드에 대해 참인 조건을 방송의
  종류에서 만들어, 조건을 모두 만족하는 코드가 그것 하나뿐이 될 때까지 4~6개를 고른다. 처음
  셋은 방송처럼 합·색의 가짓수·모양의 가짓수다. 답이 하나뿐인 것은 유닛 테스트가 14,950가지
  코드를 모두 대어 확인한다. 방송의 세 문제는 카드를 몰라 그대로 실을 수 없다.
- **판정:** 방은 "조건을 모두 만족하는가"로 본다. 저장된 코드와 비교하지 않는다.
- **라운드 수:** 3번. 다섯 명 이상이면 사람 수보다 하나 적게 (방송: 네 명, 3라운드).
  아직 못 맞힌 사람이 한 명 이하가 되면 끝난다.
- **한 라운드 4분.** 방송에 제한 시간이 없어 "방송의 절반"을 적용할 수 없었다. 시간이 다
  되거나 남은 사람이 모두 틀리면 통과자 없이 코드를 공개한다.
- **버저:** 방송은 버저를 누르고 10초 안에 답한다. 여기서는 네 장을 먼저 고르고 버저를 누르면
  그것이 답이다 (10초 규칙은 쓰이지 않는다).
- **틀린 답은 모두에게 보인다** (방송에서는 소리 내어 답했다). 그 라운드에는 더 답할 수 없다.
- **코드 공개 8초** 뒤 다음 라운드.
- **순위:** 맞힌 순서. 끝까지 못 맞힌 사람은 그 다음 순위를 함께 받는다.
- **조건의 문장:** 화면(304픽셀 폭)에 들어가도록 방송의 문장보다 짧게 썼다. 방은 조건을
  자료로 보내고 문장은 `words.ts`가 한·영으로 쓴다.
- **조작:** 카드를 누르면 고르고 다시 누르면 빠진다. 키보드는 방향키와 Space, Backspace,
  Enter(버저). 글자 키는 H(규칙)·M(음소거)·T(채팅)와 겹쳐 쓰지 않았다.
- **봇** (테스트용): 라운드 시작 90초 뒤에 정답을 낸다.
